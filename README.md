# 抖音 AI 合集作者采集

Chrome 插件：在抖音 **推荐 / 精选 / 搜索** 里收集同时满足下面三点的作者 `sec_uid`：

1. 视频挂载了**合集**
2. 带有作者声明：**内容由AI生成**
3. **内容类型属于 AI 漫剧/短剧/动画**（合集名或昵称命中白名单、且不撞黑名单）

示例视频：`https://www.douyin.com/jingxuan?modal_id=7680867175699123471`  
对应作者：吃药都要可乐送（雾山精神病院）  
`MS4wLjABAAAAIkkCPJ45b3pScDlsviQWdT6yfx5xEGV_sXn6c-xq2mz1w-XNyuH0yhL9O57Hleg4`

## 安装

1. 打开 Chrome，地址栏进入 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选择本仓库目录（包含 `manifest.json` 的文件夹）

Edge 同样可以：`edge://extensions/`。

## 用法

1. 登录 [抖音精选](https://www.douyin.com/jingxuan) 或搜索页（例如搜「漫剧」）
2. 点插件图标，或看页面右上角浮层，点 **开始采集**
3. 点 **自动下滑**：搜索/精选会持续滚内部列表加载更多；播放页会切下一条
4. 命中的作者会去重保存在本地，可复制 `sec_uid` / 导出 TXT、CSV、JSON

插件只读取你浏览器里抖音页面自己发出的推荐/搜索接口和页面上的声明文案，不会另打签名、也不会把数据上传到别处。

## 判定规则

- **合集**：接口里的 `mix_info` / `mixInfo`，或页面出现合集入口
- **AI 声明**：文案「内容由AI生成」，或 `aigc_info.aigc_label_type === 1`  
  「疑似使用AI」默认**不算**作者声明
- **内容类型**：合集名或昵称命中 AI 内容白名单（漫剧 / 短剧 / AIGC / 动画 / 番剧 等），且不命中黑名单（真人短剧 / 民间故事 / 科普 / 搬运 等）

三个条件都要满足才会入库。前两个条件可在浮层里取消勾选来放宽；**内容类型为硬门槛，不可关闭**，用于过滤真人短剧等非 AI 内容。

## 自动换栏目 / 换搜索词

- **自动换栏目**：仅在精选页生效，默认关闭，需在浮层勾选开启。按「全部 → 二次元 → 小剧场」循环切换；滚满 **40 次**或连续卡住 3 次触发。
- **自动换搜索词**：在搜索页生效，默认关闭，需在浮层勾选开启。按「品类词（AI 强绑定）+ 题材词」组合随机乱序，品类为 AI漫剧 / AI短剧 / AIGC漫剧 / AIGC短剧 / AI动画 / AIGC动画，题材为逆袭 / 重生 / 穿越 / 系统 / 校花 / 修仙 / 末世 / 都市 / 玄幻 / 悬疑 / 王妃 / 战神 / 豪门 / 复仇 / 神医 / 龙王 / 末日 / 山海 / 西游 / 宇宙 / 古代 / 志怪 / 神话 / 大明 / 传奇 / 赛博 / 聊斋 / 斗罗 / 开局 / 异世界（30 词），另加 AI 工具名「即梦 / 可灵 / Vidu / 海螺 / Runway / Pika / 剪映AI / Sora」搭配 短剧/漫剧/动画 形态（24 词），合计 204 词；滚满 **30 次**或连续卡住 3 次触发。
- 换词内置 **5 分钟全局冷却**（存于 `chrome.storage.local`，跨标签页、跨刷新、跨重启均生效），避免频繁整页刷新导致页面崩溃或触发风控。
- 栏目/搜索词切换进度用 `sessionStorage` 记录，刷新后可继续；关闭标签页后会清空、从头开始。

## 安全 / 防封提示

- 插件只被动读取浏览器里抖音页面自身发出的请求与文案，不主动发请求、不伪造签名。
- 检测到**人机验证弹窗**时，脚本会自动暂停（停下滑、停换词、停换栏目）并弹出提醒，需人工完成验证后，再点「自动下滑」恢复；请勿频繁硬刷，以免被限流或封号。
- 检测到**账号被登出 / 需要重新登录**时，脚本会自动停止采集并提醒；请重新登录后先手动浏览几分钟再重新开始，避免登录后立刻高频采集再次触发风控。
- 滑动间隔默认 **4 秒起步**（实际 2.4~5.6 秒随机，偶发 12~24 秒长停顿），已移除 2.8 秒及更快档位，降低匀速滑动被风控的概率。
- 多台电脑、多账号分发使用：务必遵守**一台 = 一个账号 + 一个 Chrome 用户（profile）**，避免作者列表串号；并让各台电脑的搜索词起点、滑动间隔略作差异，降低被抖音按行为指纹关联判定为群控的风险。
